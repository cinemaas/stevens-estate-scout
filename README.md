# Stevens Estate — location scout walk-through

Browser walk-through of the Stevens Estate Gaussian splat scan (PortalCam capture,
8 Sep 2026), for scouting and production design.

- One merged splat: LCC LOD 2, 3,928,806 gaussians, floaters removed, served as
  unbundled SOG (`tiles/stevens/meta.json` + WebP planes).
- Rendered with PlayCanvas 2.22.2.
- Lens strip frames on Super 35 (27.03 mm sensor width).
